Exercice : Manipulation basique d’Option

Contexte

Vous travaillez sur un système de gestion d’utilisateurs. Créez une classe User et implémentez des fonctions utilisant Option.

Tâches

case class User(id: Int, name: String, email: Option[String], age: Option[Int])

// 1. Créer une fonction qui retourne l'email d'un utilisateur ou "Pas d'email"
def getEmailOrDefault(user: User): String = ???

// 2. Créer une fonction qui retourne true si l'utilisateur est majeur (>= 18)
// Retourner false si l'âge n'est pas défini
def isAdult(user: User): Boolean = ???

// 3. Créer une fonction qui transforme l'email en majuscules s'il existe
def uppercaseEmail(user: User): Option[String] = ???

Testez avec

val user1 = User(1, "Alice", Some("alice@example.com"), Some(25))
val user2 = User(2, "Bob", None, Some(16))
val user3 = User(3, "Charlie", Some("charlie@example.com"), None)

Exercice : Configuration

Contexte

Vous créez un système de configuration avec des valeurs optionnelles qui doivent être validées. On distingue la configuration brute (pouvant être invalide) de la configuration validée (garantie correcte).

Tâches

// Configuration brute issue d'un fichier ou de variables d'environnement
case class RawConfig(
  host: Option[String],
  port: Option[Int],
  timeout: Option[Int]
)

// Configuration validée avec des valeurs garanties correctes
case class ValidatedConfig(
  host: String,
  port: Int,
  timeout: Int
)

// 1. Créer une fonction qui valide le port (entre 1 et 65535)
def validatePort(port: Int): Option[Int] = ???

// 2. Créer une fonction qui valide le host (non vide et non blanc)
def validateHost(host: String): Option[String] = ???

// 3. Créer une fonction qui valide le timeout (> 0)
def validateTimeout(timeout: Int): Option[Int] = ???

// 4. Créer une fonction qui transforme une RawConfig en ValidatedConfig
// Toutes les valeurs doivent être présentes et valides
def validateConfig(config: RawConfig): Option[ValidatedConfig] = ???

// 5. Créer une fonction qui construit une URL depuis une ValidatedConfig
// Format: "http://host:port"
def buildUrl(config: ValidatedConfig): String = ???

// 6. BONUS : Créer une fonction qui valide avec des valeurs par défaut
// Défauts : host = "localhost", port = 8080, timeout = 3000
def validateConfigWithDefaults(config: RawConfig): ValidatedConfig = ???

Testez avec

val validRaw = RawConfig(Some("api.example.com"), Some(443), Some(5000))
val invalidHost = RawConfig(Some(""), Some(443), Some(5000))
val invalidPort = RawConfig(Some("api.example.com"), Some(99999), Some(5000))
val partialRaw = RawConfig(None, None, Some(1000))
val completelyEmpty = RawConfig(None, None, None)

Méthodes utiles à connaître

TipMéthodes principales d’Option
  • Option.map: transforme la valeur si elle existe
  • Option.flatMap: transforme et aplatit
  • Option.getOrElse: retourne la valeur ou un défaut
  • Option.filter: filtre selon une condition
  • Option.fold: fournit une valeur par défaut et une transformation
  • Option.isDefined / Option.isEmpty: teste la présence de valeur
