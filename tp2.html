TP2 - Calculateur d’Impôt sur le Revenu

Author

Mikaël Valot

1 Introduction

1.1 Objectifs pédagogiques

Cet exercice vous permettra de découvrir et pratiquer les concepts fondamentaux de Scala :

  • Types de base (Int, Double, String)
  • case class et types algébriques (ADT)
  • Traits avec méthodes abstraites
  • Mixin de traits
  • Pattern matching

1.2 Installation

  • Installez IntelliJ Idea (dernière version)
  • Installez le plugin Scala
  • Utilisez le lien Moodle pour créer un repository GitHub classroom
  • Clonez le repo
  • Ouvrez le projet dans IntelliJ

1.3 Contexte

Vous allez développer un calculateur d’impôt sur le revenu en modélisant les foyers fiscaux. Un foyer fiscal est l’entité qui déclare et paie l’impôt (célibataire, couple, famille, etc.).

2 Modélisation de base des foyers fiscaux

2.1 Trait de base

Créez le trait de base pour tous les foyers fiscaux.

sealed trait FoyerFiscal {
  def revenuTotal: Double
  def nombreParts: Double  // Pour le quotient familial
}

2.2 Première implémentation : Célibataire

Créez une case class pour un foyer célibataire. Elle doit contenir son nom, son revenu, et doit hériter de FoyerFiscal.

2.3 Test de la Partie 1

Ajoutez ce code dans un object contenant une méthode annotée @main, et exécutez-le.

val pierre = Celibataire("Pierre Dupont", 35000.0)
println(s"${pierre.nom}: ${pierre.revenuTotal}€, ${pierre.nombreParts} parts")
// Sortie attendue: Pierre Dupont: 35000.0€, 1.0 parts

3 Trait pour les calculs d’impôt avec mixin

3.1 Trait CalculateurImpot

Créez un trait qui définit les calculs d’impôt. Ce trait nécessite l’accès au revenu et au nombre de parts :

trait CalculateurImpot {
  // Méthodes abstraites que les classes doivent fournir
  def revenuTotal: Double
  def nombreParts: Double
  
  // Méthodes concrètes qui utilisent les méthodes abstraites
  def calculerQuotientFamilial(): Double = {
    if (nombreParts > 0) revenuTotal / nombreParts else 0.0
  }
  
  def calculerTauxEffectif(impot: Double): Double = {
    if (revenuTotal > 0) (impot / revenuTotal) * 100 else 0.0
  }
}

3.2 Mixin avec Célibataire

Modifiez votre classe Celibataire pour qu’elle utilise aussi le trait CalculateurImpot.

3.3 Test

Ajoutez une méthode de test contenant le code suivant :

val marie = Celibataire("Marie Martin", 40000.0)
println(f"${marie.nom}:")
println(f"  Quotient familial: ${marie.calculerQuotientFamilial()}%.2f€")
println(f"  Taux effectif: ${marie.calculerTauxEffectif(6000)}%.2f%%")

// Sortie attendue:
// Marie Martin:
//   Quotient familial: 40000.00€
//   Impôt à 15%: 6000.00€
//   Taux effectif: 15.00%

4 Pattern matching et barème progressif

4.1 Barème progressif dans le trait

Ajoutez une méthode calculerImpotProgressif() à votre trait CalculateurImpot. Utilisez le pattern matching pour effectuer le calcul. Vous pouvez utiliser ce site pour comprendre le calcul : Simulateur Impot

Barème français simplifié :

  • 0€ à 11 497€ : 0% (exonéré)
  • 11 498€ à 29 315€ : 11% sur la tranche
  • 29 316€ à 83 823€ : 30% sur la tranche
  • 83 824€ à 180 294 : 41% sur la tranche
  • Plus de 180 295 : 45% sur la tranche

On commence par calculer le revenu par part, puis on applique le barème pour chaque tranche de revenu. Ensuite, on multiplie l’impôt calculé par le nombre de parts.

trait CalculateurImpot:
  def revenuTotal: Double
  def nombreParts: Double
  
  // Méthodes existantes...
  
  def calculerImpotProgressif(): Double = ???
}

4.2 Test

val testeurs = List(
  Celibataire("Paul", 8000.0),    // Exonéré
  Celibataire("Sophie", 20000.0), // Tranche 11%
  Celibataire("Jean", 50000.0),   // Tranche 30%
  Celibataire("Claire", 100000.0) // Tranche 41%
)

println("=== Calcul progressif ===")
testeurs.foreach { foyer =>
  val impot = foyer.calculerImpotProgressif()
  val taux = foyer.calculerTauxEffectif(impot)
  println(f"${foyer.nom}: ${impot}%.2f€ (${taux}%.2f%%)")
}

Résultats attendus :

  • Paul: 0.00€ (0.00%)
  • Sophie: 935.22€ (4.68%)
  • Jean: 8165.18€ (16.33%)
  • Claire: 24944.54€ (24.94%)

5 Autres types de foyers fiscaux

5.1 Foyer Couple

Créez une case class pour un couple. Elle doit posséder les deux noms et deux revenus, et hériter de FoyerFiscal ainsi que de CalculateurImpot. Un couple possède 2 parts fiscales.

5.2 Foyer avec enfants

Créez une case class FoyerAvecEnfants. Elle doit posséder un attribut foyerParent et un attribut nombreEnfants.

  • Les deux premiers enfants comptent pour une 1/2 part chacun.
  • A partir du 3ème enfant, chaque enfant compte pour une part complète.
  • Un parent célibataire a une 1/2 part supplémentaire.

5.3 Test

Ajoutez une méthode de test contenant le code suivant :

val celibataireSeul = Celibataire("Alice", 45000.0)
val couple = Couple("Bob", "Emma", 25000.0, 20000.0)
val celibataireAvecEnfants = FoyerAvecEnfants(Celibataire("Carol", 45000.0), 2)
val coupleAvecEnfants = FoyerAvecEnfants(couple, 1)
val coupleAvec4Enfants = FoyerAvecEnfants(couple, 4)

val foyers = List(celibataireSeul, couple, celibataireAvecEnfants, coupleAvecEnfants)

println("=== Comparaison des foyers ===")
foyers.foreach { foyer =>
  val impot = foyer.calculerImpotProgressif()
  val quotient = foyer.calculerQuotientFamilial()
  val taux = foyer.calculerTauxEffectif(impot)
  
  val nom = foyer.toString
  println(f"$nom:")
  println(f"  Revenu total: ${foyer.revenuTotal}%.2f€")
  println(f"  Nombre de parts: ${foyer.nombreParts}%.1f")
  println(f"  Quotient familial: ${quotient}%.2f€")
  println(f"  Impôt: ${impot}%.2f€")
  println(f"  Taux effectif: ${taux}%.2f%%")
  println()
}

6 Refactoring : corriger les structures de données

Avec notre structure de données, il est possible de construire ceci :

val celib = Celibataire("Alice", 45000.0)
val foyerEtrange = FoyerAvecEnfants(FoyerAvecEnfants(celib, 2), 3)

Corrigez les classes pour que cela devienne impossible.
